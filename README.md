# olist-databricks-lakehouse-pipeline
This project uses the Brazilian E_Commerece Public Dataset by Olist which contains ~100000 orders placed between 2016 and 2018 across multiple market places in Brazil.
Source : [Kaggle - Brazillian E-Commerce Public Dataset by Olist] (https://kaggle.com)
NOTE :"Due to size limit raw csv files are not uploaded" 
Developed an end-to-end e-commerce data lakehouse pipeline using Databricks, PySpark, Delta Lake and SQL. Processed and transformed Olist transactional data through Bronze, Silver and Gold layers. Built interactive Power BI dashboards to analyze sales, revenue, customer behavior, delivery performance and customer satisfaction.
